# Архитектура прошивки (ESP32 Remote)

## 1. Обзор
Пульт: Waveshare ESP32-S3 + круглый LCD 1.46" (412x412) + touch + LVGL UI.
Связь с внешними устройствами (например, Jinny Lamp): Wi-Fi STA + ESP-NOW.

Главные принципы:
- UI организован как карусель "устройств" (device screens).
- Оверлеи (brightness/speed/animation selector) блокируют глобальные свайпы.
- Diag экран всегда последний в карусели (инвариант).

## 2. Низкоуровневые драйверы и инициализация
В `app_main()` порядок инициализации:
- `Driver_Init()` (PWR/BAT/I2C/EXIO/Flash + RTC + IMU + Driver_Loop task)
- `SD_Init()`
- `LCD_Init()` (SPD2010 + Backlight + Touch)
- `Audio_Init()`
- `LVGL_Init()`
- создание экранов (device/diag/honeycomb)
- привязка animation overlay модуля
- регистрация экранов в device registry
- запуск LVGL loop (`lv_timer_handler()`)

### 2.1 Driver_Loop (периодика)
В отдельном task каждые ~100 ms:
- `QMI8658_Loop()`
- `PCF85063_Loop()`
- `BAT_Get_Volts()`
- `PWR_Loop()`

### 2.2 LCD (SPD2010) QSPI
Пины QSPI:
- TE GPIO18
- SCK GPIO40
- D0 GPIO46
- D1 GPIO45
- D2 GPIO42
- D3 GPIO41
- CS GPIO21
- Backlight GPIO5 (LEDC PWM)
Разрешение 412x412, 16 bpp.

Reset LCD:
- reset gpio = -1 (не прямой GPIO)
- reset делается через EXIO2: `Set_EXIO(TCA9554_EXIO2, false/true)`

### 2.3 Touch (SPD2010) I2C
- I2C addr: 0x53
- INT: GPIO4
- RST: -1 (не прямой GPIO)
- max points: 5

I2C шина:
- SDA GPIO10
- SCL GPIO11
- 400 kHz

## 3. Структура UI: device registry и карусель устройств
Есть реестр экранов `g_devs[]` + `g_dev_count`.

Инварианты:
- Diag экран всегда последний.
- Новые устройства вставляются перед Diag (правило insert-before-diag).

## 4. Жесты и сценарии управления (зафиксировано как инвариант UX)

### 4.1 Device screen (основной экран устройства)
- Долгий тап по верхней дуге: открыть overlay регулировки яркости (полный круг, старт справа).
- Долгий тап по нижней дуге: открыть overlay регулировки скорости (полный круг, старт справа).
- Double tap по центру: вход/выход в меню карусельного выбора анимаций.
- Удержание по центру:
  - >= `J_PAUSE_HOLD_MS` (обычно 1000 ms; допускается тюнинг): toggle pause
  - >= `J_POWER_HOLD_MS` (обычно 5000 ms): toggle power (вкл/выкл) целевого устройства
- Короткий одиночный тап по центру: ничего (исправлено, чтобы не было “pause от любого тыка”).
- Свайп влево/вправо: переключение активного device screen (другое устройство карусели).

> Примечание: центральные жесты ограничены “зоной около 1 см” (радиус), чтобы случайные касания не триггерили pause/power.

### 4.2 Animation selector (карусель выбора анимаций)
- Вертикальный свайп: прокрутка колеса выбора целиком.
- Горизонтальный свайп вправо: следующая анимация (шаг +1).
- Горизонтальный свайп влево: предыдущая анимация (шаг -1).
- Double tap: выход обратно на device screen (закрытие overlay).
- Обычные тапы внутри selector **не должны** отправлять команды на лампу (исправлено: нет “дёргания” от простого касания).

### 4.3 Приоритеты и блокировки
- При открытом overlay (brightness/speed/selector) глобальный свайп карусели устройств блокируется.
- При закрытии overlay обязательно выполняется сброс флага overlay (например, через `ui_active_dev_set_overlay(false)`).

## 5. Список эффектов (FX) и отображение имён
Пульт хранит локальный FX-кэш (список эффектов лампы) и использует его для:
- отображения имён эффектов в selector
- отображения корректного имени на device screen

Источник истины: лампа. Синхронизация кэша описана в `docs/espnow.md`.
