# Handoff: ESP32 Remote (Touch LCD)

## 0) Коротко
Пульт на ESP32-S3 с круглым дисплеем 412x412 (SPD2010 QSPI) и тачем (I2C addr 0x53),
UI на LVGL, карусель экранов устройств, управление лампой по ESP-NOW (Wi-Fi STA + ESPNOW).

## 1) Что сейчас работает (факты)
Железо/драйверы:
- Экран SPD2010 + подсветка (LEDC PWM на GPIO5).
- Touch по I2C addr 0x53, INT GPIO4.
- I2C на GPIO10/11 @ 400 kHz.
- Driver_Loop task (IMU/RTC/BAT/PWR) работает периодически.
- SD карта монтируется, LCD/Touch/Audio/LVGL поднимаются штатно.

Wireless:
- Wi-Fi STA + ESPNOW, канал фиксируется (ESPNOW-only режим).
- Peer MAC задан конфигом.
- CTRL команды отправляются, ACK принимается и логируется.
- Реализована синхронизация списка эффектов (FX sync) с лампы в кэш пульта (count+crc).

UI/UX (инварианты):
- Карусель устройств: Diag всегда последний; новые устройства вставляются перед Diag.
- Оверлеи яркости/скорости/selector блокируют глобальные свайпы.
- Device screen:
  - long press верхняя дуга: overlay яркости (полный круг, старт справа)
  - long press нижняя дуга: overlay скорости (полный круг, старт справа)
  - double tap центр: вход/выход в selector анимаций
  - удержание центр >= pause threshold: pause toggle
  - удержание центр >= power threshold: power toggle
  - короткий одиночный тап по центру: ничего (исправлено, чтобы не было “pause от любого тапа”)
- Selector:
  - вертикальный свайп: крутит колесо
  - горизонтальный: +1/-1 эффект
  - double tap: выход на device screen
  - простой тап не должен дергать лампу (исправлено)

## 2) Что осталось сделать (следующие шаги)
1) ESP-NOW: формализовать применение ACK (state_seq) как источник истины для UI (не только лог).
2) ESP-NOW: уйти от broadcast dst_node=0xFFFF к unicast (когда будет готова схема адресации).
3) Diag: заменить заглушки метрик на реальные значения (бат/uptime/rssi/fps/rtc и т.п.).
4) UX тюнинг порогов удержания (pause/power) после тестов “в руках”.
